# shadcn/ui 组件推荐

> 生成时间: 2026/2/6 13:50:45

## UI组件库

- [21st.dev](https://21st.dev/) - Open source npm for shadcn/ui components. Also: Dribble for design engineers. Install UI components via shadcn CLI, or publish your own.
- [8bitcn.com](https://www.8bitcn.com/) - A set of retro-designed, accessible components and a code distribution platform. Open Source. Open Code.
- [aceternity-ui](https://ui.aceternity.com/) - Copy paste the most trending react components without having to worry about styling and animations.
- [assistant-ui](https://github.com/Yonom/assistant-ui) - React Components for AI Chat.
- [audio/ui](https://github.com/ouestlabs/audio-ui) - A set of accessible and composable Audio UI components. Built on top of shadcn/ui, it's designed for you to copy, paste, and own.
- [autocomplete-select-shadcn-ui](https://www.armand-salle.fr/post/autocomplete-select-shadcn-ui) - Autocomplete component built with shadcn/ui and Fancy Multi Select by Maximilian Kaske.
- [auto-form](https://github.com/vantezzen/auto-form) - A React component that automatically creates a shadcn/ui form based on a zod schema.
- [async-select](https://async.rdsx.dev) - Async Select component built with shadcn/ui with debounce search.
- [berlix](https://berlix.vercel.app) - Animated components library built using Tailwind CSS and Motion
- [billingsdk](https://billingsdk.com/) - Modern, type-safe billing and subscription management components for React, built with TypeScript and Tailwind CSS. Designed to work seamlessly alongside shadcn/ui by [Dodo Payments](https://dodopayments.com/). [GitHub](https://github.com/dodopayments/billingsdk)
- [billui](https://github.com/commet-labs/billui) - Open source billing components for React built with Shadcn. Pricing cards, payment methods, invoice history and more.
- [buouui](https://buouui.com) - A UI component library and template suite based on shadcn/ui with stunning landing pages, templates, and rich animations.
